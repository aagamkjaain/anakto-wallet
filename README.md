


# anakto-wallet-

ANAKTO is a web application that serves as a modular wallet using
zkSync’s account abstraction
It has inheritance properties and spending limit functionality.
We intend to include a QR code scanner and a beneficiaries page
where the user can decide how much inheritance they want to
allocate to each beneficiary

note - completely functional crypto hot wallet with inheritence systems completely set up through smart contracts :)
